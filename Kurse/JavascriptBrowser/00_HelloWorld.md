JavaScript ist die Sprache des Webs. Sie ermöglicht es uns, Webseiten interaktiv zu gestalten. In dieser Lektion lernen wir, wie wir JavaScript nutzen, um eine Nachricht in der Konsole auszugeben.

### Wichtige Punkte:
- **Konsole:** Mit `console.log()` können wir Ausgaben für Entwickler machen.
- **Interaktivität:** JavaScript reagiert auf Klicks, Eingaben und mehr.
