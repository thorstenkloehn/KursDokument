In Java benötigen wir eine Klasse und die statische `main`-Methode, um Text auszugeben.

---
Codebeispiele
---
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.<Placeholder>println</Placeholder>("Hello World!");
    }
}
```
