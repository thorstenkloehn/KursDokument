In Java müssen Variablen vor ihrer Verwendung deklariert werden. Dabei muss der Datentyp (z. B. `int`, `double`, `String`) angegeben werden.

### Wichtige Datentypen:
- **int**: Ganze Zahlen (z. B. 42)
- **double**: Kommazahlen (z. B. 3.14)
- **String**: Texte (z. B. "Hallo Welt")
- **boolean**: Wahrheitswerte (`true` oder `false`)
---
Codebeispiele
---
```java
public class Main {
    public static void main(String[] args) {
        // Deklariere eine Ganzzahl
        <Placeholder>int</Placeholder> alter = 25;
        
        // Deklariere einen Text
        <Placeholder>String</Placeholder> name = "Thorsten";
        
        System.out.println(name + " ist " + alter + " Jahre alt.");
    }
}
```
