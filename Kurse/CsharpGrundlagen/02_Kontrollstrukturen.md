katgorie: "C# Grundlagen"
---
Kontrollstrukturen wie `if` und `else` ermöglichen es Programmen, Entscheidungen basierend auf Bedingungen zu treffen.

### Beispiel:
```csharp
if (alter >= 18) {
    Console.WriteLine("Volljährig");
} else {
    Console.WriteLine("Minderjährig");
}
```
